Sidebar identity primitives + consumer guardrails (2026-08-05 TENSOR audit — the LIBRARY/CONTRACT findings F4/F5/F8, the pill flow trap, and the sidebar-B "identity at the top" adoption).

**Tokens & CSS (`@tensor_1/tokens`)**

- **sidebar**: the "identity at the top" chrome (Linear/Notion pattern, TENSOR sidebar variant B) — `.uix-identity` (org/tenant + user as one disclosure button; compose a native `[popover]` `.uix-popover.uix-menu` for the account menu: Esc-close, light dismiss, and focus return come free), `.uix-sidebar__footer` + `.uix-sidebar__util` + `.uix-sidebar__footer-spacer` (quiet icon strip pinned to the bottom: help / theme / collapse / settings slots). Both respond to the collapsed rail: the identity shrinks to the org mark (still the trigger), the footer stacks.
- **sidebar**: `.uix-navsection` (+ `__icon`/`__label`) — the NON-INTERACTIVE section-header contract. `.uix-navitem` is now documented as **for focusable elements only** (`<a href>`/`<button>`): it ships `cursor:pointer` + a hover tint, which on a `<span>` is a false affordance (TENSOR F8: three admin nav headers looked clickable, did nothing, invisible to keyboards). A header that only labels a group takes `.uix-navsection` (same row geometry, `cursor:default`, no hover, not focusable); one that collapses its group stays a real `.uix-navgroup__trigger` button. Gated by the new `tests/a11y/nav-contract.spec.mjs` (geometry, tab-order skip, Esc focus-return, menu-open axe scan — both themes).
- **sidebar**: `.uix-navitem` no longer forces `width:100%` — as a block-level flex box it already fills the sidebar (align-stretch), while the forced width mis-sized flex-row contexts (toolbars), which consumers kept re-overriding. Sidebar rendering is unchanged (goldens re-baselined); if a consumer placed a bare `.uix-navitem` in a flex row *relying* on it claiming the full row, add `style="width:100%"` (or a flex-1 wrapper) at that call site.
- **avatar**: `.uix-avatar--org` — rounded-square org/tenant mark (distinguishes a workspace from a person), brand-muted fill.
- **menu**: `.uix-menu__dev` — a visually fenced dev-only section (dashed rule + warning-tinted label) so debug items can't be mistaken for product actions.
- **typography**: the `.uix-text-*` set is now **explicitly CLOSED** (TENSOR F5: 6 invented `type-*` classes, 36 usages, all rendering unstyled): display · h1 · h2 · h3 · body · body-hushed · meta · eyebrow · data-hero · **label (new)**. `.uix-text-label` is the standalone form-label voice (meta size, weight 500, `--uix-text`) for labels outside a `.uix-field`; inside one keep `.uix-field__label`. Migration map (`type-label` → `uix-text-label`, `type-title-sm`/`type-heading-sm` → `uix-text-h3`, `type-body-sm`/`type-caption` → `uix-text-meta`, `type-display-sm` → `uix-text-display`) documented in the styleguide's new "Type utilities" section.
- **typography**: **fixed missing from the `./styles` export** — `typography.css` was imported by the full bundle but absent from the component-only aggregate, so `@tensor_1/tokens/styles` consumers never received the `.uix-text-*` classes at all (a root cause behind the invented `type-*` family).
- **status-pill**: the flow contract is now documented + demoed — a pill is an inline chip; bare in a block wrapper it overflows its line box and eats the gap to the next sibling (TENSOR "Review required" touching the text below). Stack with `.uix-stack .uix-stack--start` (new utility: intrinsic-width children), row with `.uix-cluster`.
- **NEW `npx uix-classlint`** (ships in this package, zero-dep, `bin` + `lint/uix-classlint.mjs`): the canonical consumer-side lint for the two silent-failure classes of the audit — (1) Tailwind text-color utilities on `<button>`/`<a>` JSX (dead by design: the kit's layers beat utilities — see the new "Cascade layers vs Tailwind" section in the README and the `base.css` comment; sanctioned patterns are a component contract or an inline `--uix-*` style), (2) nonexistent `type-*` / unknown `uix-text-*` classes. Suppress per-line with `uix-classlint-ignore`. The canon list is parity-tested against `typography.css`; the packed bin is exercised by the consumer smoke test. **Product-local copies of these checks (TENSOR `slice/list-cons-01`) should be replaced by this.**

**React (`@tensor_1/react`)**

- **Sidebar**: `NavSection` (static header; renders a `<div>` — never focusable), `SidebarIdentity` (org avatar auto-initials, user line, disclosure chevron; `menuLabel` slot, `SidebarIdentityItem`/`SidebarIdentitySep` children, `devSection` fenced slot; native-popover menu with the kit's flip/shift anchoring, `aria-expanded` synced), `SidebarFooter` + `SidebarUtil` (required `label` → `aria-label`; icon-only) + `SidebarFooterSpacer`. All Beta; contract-tested in `src/sidebar-identity.test.mjs` (markup both ways + CSS drift guards, incl. rail coverage).

Consumers: TENSOR `slice/uifix-01` already re-skinned chips onto `.uix-chip[data-on]` (the pattern this release documents as sanctioned); the TENSOR **sidebar-B adoption slice** consumes the identity/footer primitives and was intentionally waiting on this release. Nothing here touches the `--uix-*` token contract (component CSS + docs + tooling only).
