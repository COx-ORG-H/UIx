**`PrintLayout`**, **`PrintSignature`**, **`PrintPageBreak`** (HAR-986 MEDx S20 findings and day list, S43 A5 poster; HAR-1252 SHOPx PRE-01 A5 poster and SHOP-03 one-page readout, folded in): a print document frame for the browser's own print. `size` `A4` / `A5` and `orientation` pick a named CSS page (`@page uix-print-a4` …) with the paper's margins; `header` and `footer` repeat on every printed page (the frame is a layout `<table role="presentation">`, because Chromium repeats a real `<thead>` / `<tfoot>` and not a CSS table of divs, measured); `pageNumbers` (default on) prints "page / pages" in the bottom-right margin; everything inside reads ink-on-paper tokens (text, surfaces, borders, table rows, and in the dark theme the tinted status backgrounds), on screen as a paper preview and on paper. `isolate` (default on): while a frame is on the page, printing shows only the frames — the app shell, its toolbars, toasts and dialogs are left out, and the containers that hold a frame become plain flow so a scroll box cannot cut it to one page; the sheet is paper even with background graphics on. `singlePage` keeps a poster or a readout in one piece, the preview is exactly one page tall, and content that does not fit is outlined and reported through `onOverflowChange`. `PrintSignature` (`label`, `name`, `placeAndDate`, `stamp`; words from `UixLabelsProvider` `printLayout`) is never split across pages; `PrintPageBreak` starts a new page. Tables inside keep their rows whole and repeat their own header row; focus rings are not printed. Utilities `.uix-print-keep`, `.uix-print-hide`, `.uix-print-only`.

New stylesheet `styles/components/print-layout.css`. A Playwright test prints a real PDF: A4 pages then the A5 poster page at their CSS sizes, the header and footer on every A4 page, the poster on one page, and the poster's QR code still scans with print media.
