`CommandPalette` items mode, the rest of roadmap #9 (enterprise UX study). `sources` run server searches as the person types: each `{ id, label, load(query, signal) }` is debounced (`debounce`, default 200 ms), asks from `minQueryLength` characters, is aborted when the next keystroke, a page change or closing overtakes it (its late answer is dropped), and lists its results as its own group after the commands, in the server's order. The rows already shown stay, dimmed and not choosable, while the next answer loads; a loading row appears only after the pending delay; a failed search shows a row that retries when chosen; the result count is announced once every source has answered, with any failure named. An item's `page` opens a nested page with its own `items` and `sources`: Escape, or Backspace in an empty field (not a held one), steps back with the query and active row restored, a breadcrumb shows the way, and closing returns to the top level. Item `aliases` find the command and are shown when they matched, "Mark done (Archive)"; a whole alias ranks like a label prefix. `contextBoost` on an item or a source ranks what fits the current screen higher without hiding anything. `useCommandFrecency()` learns how often and how lately each command is chosen (a decayed count, one small entry per command, a week's half-life), stored in `localStorage` or through an injected `storage` adapter, with `recent(items)` and `reset(id?)`; pass it as `frecency`. The ranking is the pure `rankCommandItems(items, query, { fold, frecency })`, with the fold as a parameter so the locale-aware fold can drop in; plain items rank exactly as before. New labels `commandPalette.loading`, `failed`, `retry`, `breadcrumb`. command-palette.css: `.uix-cmdk__alias`, `__chevron`, `__status`, `__retry`, `__crumbs`, `__crumb`, `__item--retry`, `__item[data-stale]`.
